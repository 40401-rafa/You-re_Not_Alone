# VOCÊ NÃO ESTÁ SOZINHO - Pasta de Imagens e Texturas

O jogo utiliza um gerador procedural dinâmico em `js/world.js` que sintetiza em tempo de execução via HTML5 Canvas 2D:
- Assoalho de madeira escura com ranhuras e pregos;
- Papel de parede vitoriano carmesim com mofo e descascamentos;
- Teto com gesso rachado e infiltrações;
- Azulejos com fungos do banheiro;
- Portas de madeira com fechaduras de latão;
- Retratos sombrios da família cujos olhos parecem seguir o jogador;
- Paredes com arranhões de sangue ("NÃO OLHE PARA TRÁS");
- Tela de tubo CRT com estática analógica animada;
- Silhueta espectral esfumaçada de "O Observador" com olhos brancos brilhantes.

Texturas personalizadas adicionais podem ser inseridas aqui para substituição em futuras expansões.
